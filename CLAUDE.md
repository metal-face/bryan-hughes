# CLAUDE.md

Personal landing page. Vite + React 19 SPA with TanStack Router (file-based, router only, no TanStack Start/SSR) and Tailwind CSS 4. Package manager: pnpm.

## Commands

- `pnpm dev`: dev server on port 3000
- `pnpm build`: production build
- `pnpm check`: Biome lint + format check; `pnpm exec biome check --write src index.html` to fix
- `pnpm exec tsc --noEmit`: typecheck (no script for it)

## Conventions

- Biome style: tabs, double quotes. Run the fix command after editing.
- Import alias `#/*` maps to `src/*` (package.json `imports`).
- `src/routeTree.gen.ts` is generated by the router plugin. Never edit it.
- Dark mode is class-based (`@custom-variant dark` in `src/styles.css`). Use `dark:` utilities; the `.dark` class is set on `<html>` by the script in `index.html` and by the toggle.
- One component per file in `src/components/`, as named exports; route files hold only the page layout. Import via `#/components/...`.
- Links live in `LINKS` in `src/routes/index.tsx`; skills in `SKILLS` in `src/components/SkillsMarquee.tsx`. Skill icons are Simple Icons slugs from the jsdelivr CDN (pinned version); verify a slug exists before adding it.
- Keep the marquee accessible: the duplicate list stays `aria-hidden`, and motion stops under `prefers-reduced-motion`.
