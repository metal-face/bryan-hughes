# bryan-hughes.com

Personal landing page for Bryan Hughes: name, title, links (GitHub, resume, Blog Builder), a looping skills marquee, and a light/dark toggle.

## Stack

- [React 19](https://react.dev) + TypeScript
- [Vite 8](https://vite.dev), a client-side SPA (no SSR)
- [TanStack Router](https://tanstack.com/router) with file-based routing
- [Tailwind CSS 4](https://tailwindcss.com)
- [Biome](https://biomejs.dev) for linting and formatting
- pnpm

## Getting started

```bash
pnpm install
pnpm dev
```

The dev server runs at http://localhost:3000.

## Scripts

| Command | What it does |
| --- | --- |
| `pnpm dev` | Start the dev server on port 3000 |
| `pnpm build` | Build for production into `dist/` |
| `pnpm preview` | Serve the production build locally |
| `pnpm check` | Lint and format check (Biome) |
| `pnpm lint` | Lint only |
| `pnpm format` | Format check only (`pnpm exec biome check --write` applies fixes) |
| `pnpm generate-routes` | Regenerate `src/routeTree.gen.ts` without running Vite |

## Project layout

```
index.html              Fonts, meta tags, pre-paint theme script
src/main.tsx            App entry, creates the router
src/routes/__root.tsx   Root layout (imports styles.css)
src/routes/index.tsx    The landing page: hero, skills marquee, theme toggle
src/styles.css          Tailwind setup, theme fonts, marquee animation
src/routeTree.gen.ts    Generated by the router plugin; do not edit
```

## Editing content

- **Links and skills:** the `LINKS` and `SKILLS` arrays at the top of `src/routes/index.tsx`.
- **Skill icons:** each skill's second value is a [Simple Icons](https://simpleicons.org) slug, loaded from the jsdelivr CDN and tinted with the text color.
- **Theme:** dark mode uses a `.dark` class on `<html>`. The script in `index.html` applies the saved choice (or the OS setting) before first paint.
